dside events — three warm directions. Real home page HTML and event page HTML, each rendered three times under a different token set. Every direction defaults to light; use its toggle for the dark palette. Links go nowhere; the Interested buttons toggle locally so you can judge the pressed look. Self-contained file, no network.

Direction 1 — Paper and ink

Warm uncoated paper, espresso ink, stamp-red links; one old-style serif for everything, like the folded programme you pick up at the door of an open-air cinema.

Rendering with the system stack (Palatino Linotype / Palatino / P052 / Georgia / Noto Serif). Optional self-hosted face Alegreya (OFL) is NOT loaded here.
